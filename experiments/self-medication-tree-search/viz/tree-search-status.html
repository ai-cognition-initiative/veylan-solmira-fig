Tree search over steered self-instances

A model branches into copies of itself, each running a different steering “compound”, and searches for the best.

Illustrative — the numbers come from a toy objective (weights picked by hand), not the model. They show the search finds a late-payoff line, not any real steering result.

The horizon test

Best line is anxious → focused — a compound that looks weak alone but unlocks a jump next step. A chess sacrifice.

A narrow beam keeps the top-2 and drops anxious — so it never reaches the 2.70. Keep the weak node alive (revival / best-first) and the line pays off.
